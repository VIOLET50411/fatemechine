# 天机阁 · 东西玄学通义算命系统 (Tianji Pavilion)

> **参赞天地化育 · 洞悉心象机微**  
> 融合中国风水八卦、四柱八字五行生克与西方塔罗原型象征的沉浸式交互占卜网站。

---

## 🌟 核心特色与功能

1. **水墨国风全交互体验**：
   - 78张古朴水墨国风牌面（含大阿卡纳与四大元素牌组）。
   - 130° 抛物线 3D 扇形展开选牌池，悬停上浮光效。
   - 真实 3D 翻牌物理动效，自适应正逆位与五行光环。

2. **四柱八字排盘与五行旺衰**：
   - 阳历生辰便捷输入，后台自动推算年柱、月柱、日柱、时柱。
   - 精准计算本命日元、五行得分雷达与喜用神/忌神。
   - 支持「通俗白话」与「专业命理」一键随时切换。

3. **八卦时空罗盘定向**：
   - 支持移动端设备陀螺仪/电子指南针感测，随身旋转实时锁定坐向。
   - 支持桌面端精细旋转罗盘与 8 个主要方位一键切换。

4. **双模式深度解盘**：
   - **通俗极速版**：本地毫秒级生成一句话天机总揽、五行雷达图、三才阵位详解与居家/办公风水实操调理指南。
   - **DeepSeek 深度解盘**：流式接入 DeepSeek 大模型（四级标题切片渲染、象气交感、时空溯源、境物相调）。

5. **实用辅助功能**：
   - 历次占卜结果自动持久化至本地历史抽屉。
   - 一键格式化复制解盘长文摘要，便于分享。

## 🛠️ 技术架构

- **前端架构**：原生 HTML5 + 现代化 Vanilla CSS (CSS 3D Transforms, Fluid Typography) + Vanilla JavaScript (ES6+)。
- **核心计算引擎**：
  - `js/tarot-data.js`：78张塔罗牌五行八卦与四大诉求释义数据库。
  - `js/bazi-engine.js`：儒略日公历转天干地支、五虎遁/五鼠遁排盘与日元旺衰算法。
  - `js/fengshui-engine.js`：八卦九宫方位映射、五行生克与 SVG 雷达平衡计算。
  - `js/reading-engine.js`：结构化解盘报告与风水实操指南生成器。
  - `js/deepseek-client.js`：DeepSeek API SSE 流式客户端与 Markdown 排版渲染器。
  - `js/card-interaction.js` & `js/compass.js`：3D 物理交互与传感器控制器。
